Historial de fases

La evolución de Pollo Assistance, fase por fase. Del chat inicial al ecosistema developer completo.

Esta página documenta los hitos añadidos a Pollo Assistance a lo largo del tiempo. Cada "fase" agrupa un conjunto coherente de funcionalidades lanzadas juntas. La fase más reciente se resalta en naranja arriba.

FPollo CODE — ecosistema developer

2026 · actual

Full rewrite of the development experience: a separate page like Claude Code/Codex, GitHub and Google Drive connections, file system tools, live preview with screenshot, voz, multimodal file uploads. The AI works inside the user's own repo or folder, never on Pollo's servers.

  • 3 tiers de CODE — Palos / Luces / Summum, sharing the same Pool de IAs as normal chat.
  • OAuth Device Flow de GitHub — escritura directa a repos con retry ante sha race.
  • Integración Google Drive — trabaja en cualquier carpeta; auto-reconexión si el token caduca (~1h).
  • Tools fs_* — listDir, readFile, writeFile, deleteFile. Modal de permisos en modo "ask".
  • Visor en vivo — iframe sandbox con pestañas, captura de console, screenshot, handle de resize.
  • Voz (STT + TTS) — API nativa del navegador, sin coste Whisper.
  • Subida multimodal — drag imágenes/code into the chat, the brain routes to a vision-capable AI if needed.
  • Revenue split para extensiones — devs FREE 35%, devs Premium 80%.
Subfases internas:
  • F.5.0UI desde cero en /code.html
  • F.5.1Device Flow de GitHub + wrapper REST API
  • F.5.2OAuth Google Drive + persistencia de chat source-aware
  • F.5.3Specialist real con tools, proxy al cerebro normal
  • F.5.4Visor en vivo, html2canvas, captura de console, subida de archivos
  • F.5.5Editor de extensiones con badge de revenue + cargar desde Files
  • F.5.6Sanity check + sistema de strikes + headers de plan de coste
  • F.6Whisper-less voz (Web Speech API STT + TTS per message)
  • F.7Historial wiki + traducciones EN/ES completas (esta página)

EPollo FILES — análisis de documentos

2025 · Q4

Filesystem por usuario almacenado 100% en Firestore (sin Cloud Storage). La IA puede leer, editar y referenciar documentos del usuario directamente desde el chat. Cuotas por tier: Palos 0, Luces 2MB, Summum 10MB.

  • Filesystem nativo dentro de Pollo Assistance.
  • Contadores atómicos por usuario y por chat (transacciones Firestore).
  • Explorador web de archivos con visor + subida.
  • Cuotas de escritura por tier; Palos no tiene filesystem.

DCompartir + compresión de chats

2025 · Q3

Chats compartidos con enlace público (solo lectura). Cuando una conversación se alarga, se auto-comprimen los turnos antiguos en un resumen para que la IA mantenga el hilo sin romper el contexto.

  • Compartir chats públicos con botón "Compartir" tipo Google Docs.
  • Compresión automática de mensajes viejos a resumen.
  • Reacciones y feedback (thumbs up/down) en respuestas IA.

CSistema de tiers + cerebro selector

2025 · Q2

Nace la identidad de Pollo: Palos, Luces y Summum. Cada tier tiene un modelo "cerebro" asociado que elige, de forma dinámica, qué IA del pool responde a cada mensaje del usuario según el tipo de tarea.

  • Palos: rápido y directo. Pool: Llama 3.1 8B + Laguna XS2.
  • Luces: equilibrado. Pool: Llama 3.3 70B + Qwen, Llama 4 Scout, GPT-OSS-20B, etc.
  • Summum: max power. Pool: Mistral Grande, DeepSeek R1, Gemini, Kimi K2, etc.
  • Cerebro con chain de fallbacks: si el principal falla, baja al secundario, al terciario, después al heurístico.
  • Toast "X está al mando": indicador visible de qué IA contestó.

BAuth + proxy en Cloudflare Worker

2025 · Q1

Cuentas de usuario vía Firebase Auth. Todas las llamadas a IA pasan por un Cloudflare Worker (pollo-luces-proxy) que añade la API key server-side — las claves nunca llegan al navegador. Conteo de créditos por usuario.

  • Correo electrónico + Google authentication.
  • Sistema de débito por tokens con límites diarios y mensuales.
  • Cloudflare Worker como proxy con chain de fallback entre providers.
  • Panel de admin para monitorización de usuarios y créditos.

AInitial release — chat, voz and imágenes

2024

First version of Pollo Assistance: basic chat con IA with text-to-speech, voz-to-text and generación de imágenes. Cute mascot, "rotating ai logo" effect, single welcome interface.

  • chat con IA with multimodal input (text + image).
  • Voz (TTS) and voz-to-text (STT) integrated.
  • Generación de imágenes via Pollinations.
  • Historial de chats guardado en Firestore.

Qué viene después

Tras F.7, Pollo Assistance es feature-complete para la v1. Mejoras futuras previstas:

  • Fase G: dominio polloassistance.com end-to-end (Auth domains, OpenGraph, sitemap, SEO completo).
  • Marketplace público de extensiones: donde los devs publiquen y los usuarios instalen extensiones comunitarias.
  • API programable: apps externas podrán llamar a Pollo Assistance vía token de API.

Un ecosistema construido pieza a pieza

Each phase added a specific capability without breaking the previous ones. The architecture (Firebase Hosting + Firestore + Cloudflare Workers, no Cloud Storage, sin suscripciones mensuales) has stayed the same since Phase B.
