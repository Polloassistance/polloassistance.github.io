Por qué es diferente Activo

Pollo CODE trabaja dentro de tu propio repo de GitHub o carpeta de Drive. La IA lee, escribe y edita archivos directamente ahí, nunca en servidores de Pollo. Ves los cambios commit a commit en tu repo. Sin bloqueo de proveedor.

Workspaces

🐙

GitHub

Device Flow OAuth, sin necesidad de client secret. La IA hace commits directos a la rama que elijas. Auto-retry ante conflictos de sha.

📁

Google Drive

OAuth vía Google Identity Services. Elige cualquier carpeta. Modal de reconexión automática si el token caduca (~1 hora).

Modos de permisos

🛡️

Ask (por defecto)

Antes de cada escritura o borrado, un modal aparece con la ruta del archivo y una vista previa del contenido. Apruebas o rechazas.

⚡

Auto

La IA escribe/borra sin confirmación. Más rápido, menos seguro. Recomendado para repos personales con control de versiones.

Visor en vivo

Un panel lateral acoplado a la derecha con pestañas y herramientas estilo Chrome DevTools:

  • Pestaña Preview: renderiza HTML/CSS/JS de tu workspace en un iframe sandbox. El visor inline-a los <link> y <script src> de archivos vecinos automáticamente.
  • Pestaña Console: captura console.log/warn/error y errores no controlados del iframe. Con timestamps y badges de nivel coloreados.
  • Botones de acción: recargar, screenshot (PNG vía html2canvas), abrir en nueva pestaña, cerrar.
  • Handle de resize: arrastra el borde izquierdo para hacer el panel más estrecho o ancho. Se guarda entre sesiones.

Subida de archivos

Adjunta imágenes o archivos de texto/código directamente a tu mensaje (o arrástralos al textarea). Límites:

  • Imágenes: máx 8 MB cada una. Hasta 4 adjuntos por mensaje.
  • Texto/código: máx 80 KB cada uno. Archivos más grandes deberían estar en el workspace y leerse con fs_readFile.

Si adjuntas una imagen, el cerebro elige automáticamente una IA con visión (Llama 4 Scout, Gemini Flash, etc.) para que pueda analizar la imagen.

Voz

El botón del micrófono usa la API nativa Web Speech del navegador (Chrome / Edge). Gratis, instantáneo, con transcripción en vivo mientras hablas. Cada respuesta de la IA tiene un botón 🔊 para escucharla.

Consejo: Usa el botón 📁 Load en el editor de extensiones para importar un proyecto guardado con ☁ Save to Files — los archivos del proyecto aparecen listos para editar en segundos.
