Phase history

Pollo Assistance's evolution, phase by phase. From the initial chat to the full developer ecosystem.

This page documents the milestones added to Pollo Assistance over time. Each "phase" groups a coherent set of features released together. The most recent phase is highlighted in orange at the top.

FPollo CODE — developer ecosystem

2026 · current

Full rewrite of the development experience: a separate page like Claude Code/Codex, GitHub and Google Drive connections, file system tools, live preview with screenshot, voice, multimodal file uploads. The AI works inside the user's own repo or folder, never on Pollo's servers.

  • 3 CODE tiers — Palos / Luces / Summum, sharing the same AI pool as normal chat.
  • GitHub OAuth Device Flow — direct write to repos with retry on sha race.
  • Google Drive integration — work on any folder; auto-reconnect if token expires (~1h).
  • fs_* tools — listDir, readFile, writeFile, deleteFile. Permission modal in "ask" mode.
  • Live viewer — iframe sandbox with tabs, console capture, screenshot, resize handle.
  • Voice (STT + TTS) — native browser API, no Whisper costs.
  • Multimodal uploads — drag images/code into the chat, the brain routes to a vision-capable AI if needed.
  • Revenue split for extensions — FREE devs 35%, Premium devs 80%.
Internal sub-phases:
  • F.5.0UI from scratch in /code.html
  • F.5.1GitHub Device Flow + REST API wrapper
  • F.5.2Google Drive OAuth + source-aware chat persistence
  • F.5.3Real specialist with tools, normal-brain proxy
  • F.5.4Live viewer, html2canvas, console capture, file uploads
  • F.5.5Extension editor with revenue badge + load from Files
  • F.5.6Sanity check + strike system + cost plan headers
  • F.6Whisper-less voice (Web Speech API STT + TTS per message)
  • F.7Wiki history + complete EN/ES translations (this page)

EPollo FILES — document analysis

2025 · Q4

Per-user file system stored 100% in Firestore (no Cloud Storage). The AI can read, edit and reference user documents directly from the chat. Tier quotas: Palos 0, Luces 2MB, Summum 10MB.

  • Native file system in Pollo Assistance.
  • Atomic counters per user and per chat (Firestore transactions).
  • Web-based file explorer with viewer + upload.
  • Per-tier write quotas; Palos has no file system.

DSharing + chat compression

2025 · Q3

Shared chats with public link (read-only). When a conversation gets too long, it auto-compresses the old turns into a summary so the AI keeps the thread without breaking context.

  • Public chat sharing with Google Docs-style "Share" button.
  • Automatic compression of old messages into summary.
  • Reactions and feedback (thumbs up/down) on AI responses.

CTier system + brain selector

2025 · Q2

Pollo's identity is born: Palos, Luces and Summum. Each tier has an associated "brain" model that chooses, dynamically, which AI from the pool answers each user message based on the type of task.

  • Palos: fast and direct. Pool: Llama 3.1 8B + Laguna XS2.
  • Luces: balanced. Pool: Llama 3.3 70B + Qwen, Llama 4 Scout, GPT-OSS-20B, etc.
  • Summum: max power. Pool: Mistral Large, DeepSeek R1, Gemini, Kimi K2, etc.
  • Brain with fallback chain: if main brain fails, falls to secondary, tertiary, then heuristic.
  • "X is in charge" toast: visible indicator of which AI answered.

BAuth + Cloudflare Worker proxy

2025 · Q1

User accounts via Firebase Auth. All AI calls go through a Cloudflare Worker (pollo-luces-proxy) that adds the API key server-side — keys never reach the browser. Per-user credit metering.

  • Email + Google authentication.
  • Token-based debit system with daily and monthly limits.
  • Cloudflare Worker as proxy with provider fallback chain.
  • Admin panel for monitoring users and credits.

AInitial release — chat, voice and images

2024

First version of Pollo Assistance: basic AI chat with text-to-speech, voice-to-text and image generation. Cute mascot, "rotating ai logo" effect, single welcome interface.

  • AI chat with multimodal input (text + image).
  • Voice (TTS) and voice-to-text (STT) integrated.
  • Image generation via Pollinations.
  • Chat history saved in Firestore.

What's coming next

After F.7, Pollo Assistance is feature-complete for v1. Future improvements expected:

  • Phase G: end-to-end polloassistance.com domain (Auth domains, OpenGraph, sitemap, full SEO).
  • Public extension marketplace: where devs publish and users install community extensions.
  • Programmable API: external apps will be able to call Pollo Assistance via API token.

An ecosystem built piece by piece

Each phase added a specific capability without breaking the previous ones. The architecture (Firebase Hosting + Firestore + Cloudflare Workers, no Cloud Storage, no monthly subscriptions) has stayed the same since Phase B.
