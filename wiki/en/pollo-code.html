Pollo CODE

Pollo Assistance inside your terminal. It reads and writes your project's files and runs real commands, in whatever folder you're standing in.

What it isA terminal program you install on your computer
Commandpollo
RequiresNode.js 18 or newer
SystemsWindows, macOS and Linux
Downloadpolloassistance.com/code.html
QuotaThe same one as the web: nothing extra to pay
This changed in October 2026. Pollo CODE used to be an editor inside the browser, with workspaces and a live preview. It is now a terminal program. This page describes what exists today.

Installing it

One line. The download page detects your system and gives you the right one.

SystemCommand
Windowsirm https://polloassistance.com/descargas/instalar.ps1 | iex
macOS and Linuxcurl -fsSL https://polloassistance.com/descargas/instalar.sh | sh
If you don't have Node.js, the installer tells you so and explains how to get it, instead of failing halfway with a strange error.

Linking your computer

When you type pollo login, the terminal shows you an eight-letter code and sends you to a page to confirm it from your account. You type the code, approve it, and the terminal is linked.

The code you see is not the key. The real key is generated by your computer, never appears on screen and never travels anywhere you could read it. That's why the code can be short and easy to type without weakening anything: on its own it opens nothing.

Every linked machine shows up in your settings, and you can kick any one of them out without touching the others. Once revoked, that terminal stops identifying you on its very next request.

How you use it

It works in the folder you're in. There's no project to open or configure.

CommandWhat it does
polloOpens the session in this folder
pollo loginLinks this computer to your account
pollo logoutDeletes this computer's key
pollo modelosThe models, and which one is set
pollo --demoSee the interface with no account and no quota spent
pollo --nuevoStart without resuming the previous conversation

And inside the session:

InsideWhat it does
/modeloSwitch model halfway through
/cuotaWhat you have left today
/limpiarStart over and forget what was said
/ayudaWhat you can do
/salirClose the session
Ctrl+C once cuts the turn and keeps what was done; twice exits. A Ctrl+C that kills the whole session mid-job is a way to lose things.

What it can do

Read your files

Looks at the folder and opens what it needs to understand the project.

Write and fix

Creates files, changes specific parts and deletes what's left over.

Run commands

Runs whatever is needed and reads the output to correct itself.

Run Python

Real scripts, with their results coming back.

The conversation stays in the folder

While working in a folder, Pollo leaves a .pollo/ inside it with what you talked about. Come back days later and it carries on where you left off.

It searches upwards, the way git does. Opening the terminal in my-project/src/components resumes the conversation from my-project: it's the same project, and the opposite would mean a different conversation in every subfolder.

It lives on your computer on purpose, not in the cloud. The conversation carries pieces of your files inside it, and uploading that to a server would mean taking your code off your machine to solve something a file next to it solves. It also works offline and costs no quota.
Your key is never stored there. It lives separately, in your home folder. And .pollo/ brings its own .gitignore, so the conversation doesn't end up in a commit by accident.

The models

The same three as the web, and you pick. Razonamiento is the default, because Complejo eats the day's quota in a handful of turns and that is worth choosing on purpose, knowing what it costs.

Why it has no dependencies

Node already ships everything this needs. Every dependency is one more thing that can break, that has to be updated and that somebody has to audit — and this is a program that reads and writes inside your folders, so the less third-party code running in there, the better.
